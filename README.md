# Snow Goose App Scaffold

Phase 1 scaffold for the Snow Goose Inn operations web app.

## Included
- Supabase SQL schema and seed data
- TypeScript domain types
- React/Next app route structure
- Dashboard, time entry, payroll, inventory, maintenance starter pages
- Core pay calculation helpers

## Suggested stack
- Next.js + React + TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Setup outline
1. Create a Supabase project.
2. Run `supabase/schema.sql`.
3. Add environment variables for Supabase.
4. Create a Next.js app and copy `src/` into it, or use these files as the project base.
5. Connect PDF/email services in phase 2 of implementation.
